# SF6Viewer v2.4.2

2026-09-06

최근 대전 피드에서 MR 증감이 한 경기씩 밀려 표시되던 문제를 수정했습니다. 경기별 MR을 계산할 수 있는 근거에 따라 추정치와 확인 상태를 구분합니다.

## 주요 변경 사항

- **경기별 MR 증감 수정**: 경기 시작 MR끼리의 차이를 다음 경기의 결과에 붙이던 오류를 수정했습니다. 이제 같은 캐릭터로 이어진 다음 경기의 시작 MR에서 해당 경기의 시작 MR을 빼서, 해당 경기의 증감을 계산합니다.
- **추정치 명시**: 수집 기록에서 두 경기가 연속으로 관측되었고 MR과 경기 결과가 일치하는 경우에만 `추정 ▲ +8 MR`처럼 표시합니다. Buckler의 명시적인 경기 종료 MR을 받은 값은 아니므로 추정치로 안내합니다.
- **확인 상태 구분**: 유효한 MR이 있으나 다음 경기의 기록이 아직 없으면 `MR 확인 중`을 표시합니다. MR 누락, 연속 여부를 확인할 수 없는 기록, 서로 상충하는 기록 등은 `MR 확인 불가`로 표시합니다.
- 기존 데이터베이스의 전적과 수집 기록을 그대로 사용합니다. 업데이트를 위해 데이터를 지우거나 다시 수집할 필요가 없으며, 기존 기록도 확인 가능한 근거에 따라 표시합니다.

## 다운로드 및 업데이트

1. 실행 중인 SF6Viewer를 종료합니다.
2. Windows용 [`SF6Viewer.exe`](https://github.com/blacknabis/SF6RankViewer/releases/download/v2.4.2/SF6Viewer.exe)를 내려받아 기존 실행 파일을 교체합니다.
3. 새 실행 파일을 실행한 뒤 앱에 표시된 버전이 **2.4.2**인지 확인합니다.

Python 설치는 필요하지 않습니다. Google Chrome 또는 Microsoft Edge와 Microsoft Edge WebView2 Runtime이 설치되어 있어야 합니다.

기존 V2 사용자는 같은 Windows 사용자 환경에서 업데이트하면 `%LOCALAPPDATA%\SF6Viewer`에 저장된 전적과 설정이 유지됩니다. 데이터 폴더 삭제나 전적 초기화는 필요하지 않습니다.

## OBS 연결

- 권장 크기: **1400 × 180**
