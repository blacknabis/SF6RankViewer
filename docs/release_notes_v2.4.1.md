# SF6Viewer v2.4.1

2026-09-06

전적 수집 상태를 더 정확하게 표시하고, 첫 수집과 닉네임 변경, OBS 갱신에서 발생하던 예외 상황을 보완했습니다.

## 주요 변경 사항

- **수집 상태 확인 개선**: 마지막 대전 수집 성공 시각과 수집 실패·갱신 지연을 화면에 표시합니다. 자동 수집 실패도 작업 이력과 로컬 진단 로그에 기록합니다.
- **강제 종료 후 상태 복구**: 수집 중 앱이 강제 종료되어 남은 미완료 작업을 재시작 시 중단 상태로 정리합니다.
- **첫 수동 수집 개선**: 처음 로그인한 뒤 자동 수집을 켜지 않아도 **최근 대전 수집**을 사용할 수 있도록, 필요한 프로필을 먼저 확인합니다.
- **닉네임 변경 대응**: 닉네임이 바뀐 뒤 같은 경기를 다시 수집하면 충돌로 잘못 격리되던 문제를 수정했습니다. 보존된 원본을 이용해 기존 기록과도 호환되도록 처리합니다.
- **OBS 갱신 복구**: 요청이나 응답 본문이 끝나지 않을 때 제한시간 이후 요청을 취소하고 다음 갱신 주기에 다시 시도합니다.
- 정적 검사 오류를 정리하고, 전적 초기화 안내를 실제 동작에 맞게 수정했습니다.

## 다운로드 및 업데이트

1. 실행 중인 SF6Viewer를 종료합니다.
2. Windows용 [`SF6Viewer.exe`](https://github.com/blacknabis/SF6RankViewer/releases/download/v2.4.1/SF6Viewer.exe)를 내려받아 기존 실행 파일을 교체합니다.
3. 새 실행 파일을 실행한 뒤 앱에 표시된 버전이 **2.4.1**인지 확인합니다.

Python 설치는 필요하지 않습니다. Google Chrome 또는 Microsoft Edge와 Microsoft Edge WebView2 Runtime이 설치되어 있어야 합니다.

기존 V2 사용자는 같은 Windows 사용자 환경에서 업데이트하면 `%LOCALAPPDATA%\SF6Viewer`에 저장된 전적과 설정이 유지됩니다. 업데이트를 위해 데이터 폴더를 삭제하거나 전적을 초기화할 필요가 없습니다.

전적 초기화는 이전 기록을 화면과 통계에서 숨기는 기능입니다. 원본 수집 데이터는 보존되지만, 현재 앱에는 초기화 취소나 저장 원본 재처리 기능이 없습니다.

## OBS 연결

- 브라우저 소스 URL: `http://127.0.0.1:8000/ui/obs.html`
- 권장 크기: **1400 × 180**

앱을 실행한 상태에서 사용하세요. 기존 OBS 브라우저 소스 주소는 그대로 사용할 수 있습니다.
