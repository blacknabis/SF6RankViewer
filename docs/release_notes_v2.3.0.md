# SF6Viewer v2.3.0 릴리스 노트 (GitHub Release)

## 🎮 주요 변경 사항

### ⚡ 마지막 플레이 캐릭터 기준 전적 및 MR 차트 자동 분리
- **개요**: 주 캐릭터와 부 캐릭터를 번갈아 가며 플레이할 때, 전적과 MR 변동이 섞이지 않고 **가장 최근에 플레이한 내 캐릭터** 기준으로 전적과 MR 차트가 자동으로 분리되어 표시됩니다.
- **적용 범위**:
  1. **Total (전체 전적)**: 최근 플레이한 내 캐릭터의 전체 승/패/승률 집계
  2. **Recent 100 (최근 전적)**: 최근 플레이한 내 캐릭터의 최근 100경기 승/패/승률 집계
  3. **MR Flow (MR 차트)**: 최근 플레이한 내 캐릭터의 MR 변동 추이만 그래프에 표시
  4. **vs 상대 캐릭터 / vs 상대 유저**: 현재 내 캐릭터 기준으로 상대 전적 집계
